RoboBlast TPS: mobile touch build

This is a non-commercial fan build of GDQuest's Godot 4 3D third-person controller demo (original demo: gdquest-demos.github.io). It was made with Godot 4.7.2 and is not endorsed by GDQuest.

Modifications

Added on-screen touch controls (stick, drag to look, Jump/Fire/Aim/Swap/Pause), a camera hook for touch look, no pointer capture on touch devices, a fix for a release-export parse error in a debug-only script, and a compressed game-data loader for static hosting. The changed source files are in the source-changes/ folder of this site's repository. They are MIT for code and CC BY-NC-SA for any art.
